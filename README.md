# WERKE 🤖

### AI-Powered Conversational Assistant

WERKE is an AI conversational web application currently being developed using
Next.js, TypeScript, React, and Google Gemini.

The goal of WERKE is to create a simple and useful AI assistant that can
understand user queries and generate helpful responses through a modern
chat-based interface.

> 🚧 WERKE is currently under active development.

## 📂 Project Architecture

The application uses the Next.js App Router architecture.

Important parts of the project include:

app/
├── api/
│   ├── chat/
│   │   └── route.ts
│   └── generate/
│       └── route.ts
├── globals.css
├── layout.tsx
└── page.tsx

The API routes handle communication between the application and the AI model.

---

## 🔐 Environment Variables

API credentials are stored using environment variables and are not intended
to be committed to the public repository.

Example:

GEMINI_API_KEY=your_api_key_here

## 💻 Running the Project Locally

Clone the repository:

git clone https://github.com/singhjaskirat45400-lab/ai-study-app.git

Enter the project directory:

cd ai-study-app

Install dependencies:

npm install

Create a `.env.local` file and configure the required Gemini API key.

Then start the development server:

npm run dev

Open:

http://localhost:3000
